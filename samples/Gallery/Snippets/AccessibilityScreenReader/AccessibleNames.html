An accessible name is a short, descriptive text string that a screen reader uses to describe a UI element.

Typically, the accessible name should be short and match the visual label of the control. Screen reader users will hear this name every time they navigate to that control.

If the control's content can be converted to a string, an accessible name is automatically determined from the visible text. However, elements such as images or input fields need to have a custom accessible name.

See Expose basic accessibility information#Accessible name and Expose basic accessibility information#Name from inner text.
