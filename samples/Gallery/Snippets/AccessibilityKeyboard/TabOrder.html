To use the keyboard with a control, the control must have focus. The most common way to receive focus is via Tab navigation, which cycles through controls that are tab stops. The order of these tab stops is called the tab order.

All interactive controls, like buttons, should be tab stops (unless they are in a group that's accessible in some other way), but non-interactive controls, like labels, should not. Try to put initial focus on the most useful or logical element.
